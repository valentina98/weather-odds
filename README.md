# weather-odds

Historical weather odds for planning outdoor activities (gatherings, hikes, walks) 1–3 months ahead.

Pick a place and a date range, and weather-odds tells you what the weather has *usually* been like on those days in past years: typical temperatures, the chance of rain or snow during your event hours, wind, and recurring seasonal patterns. It is a climatology tool, not a forecast.

**Status:** definition phase. No application code yet. The research and the draft specification are being written in pull requests; open questions are tracked as GitHub issues.
